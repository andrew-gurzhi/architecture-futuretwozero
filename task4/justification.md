# Обоснование архитектуры инфраструктуры

## Выбор ресурсов

### 1. VPC и сеть
Создана отдельная VPC для изоляции инфраструктуры.

Преимущества:
- безопасность
- контроль сетевого трафика
- масштабируемость

---

### 2. Kubernetes (EKS)
Используется для запуска микросервисов.

Причины:
- масштабируемость
- отказоустойчивость
- стандарт индустрии

---

### 3. S3 (Data Lake)
Используется для хранения аналитических данных.

Причины:
- дешёвое хранение
- высокая доступность
- интеграция с аналитическими инструментами

---

### 4. PostgreSQL
Используется для транзакционных данных.

Причины:
- управляемый сервис
- резервное копирование
- отказоустойчивость

---


## Преимущества IaC

### 1. Воспроизводимость
Инфраструктура разворачивается одинаково в любой среде.

---

### 2. Масштабируемость
Легко добавлять новые ресурсы.

---

### 3. Контроль изменений
Все изменения версионируются.

---

### 4. Автоматизация
Минимизация ручных ошибок.

---

## Связь с бизнес-целями

- Быстрое масштабирование → облако + Kubernetes
- Быстрая аналитика → S3 Data Lake
- Надёжность → managed сервисы
- Быстрый time-to-market → IaC + автоматизация
