# Задание 3. Технологический радар и роадмап изменений

## 1. Технологический радар

Технологический радар отражает текущее состояние и целевые изменения в IT-ландшафте компании «Будущее 2.0».

### Категории:

- Adopt — активно внедряем
- Trial — пилотируем
- Assess — оцениваем
- Hold — устаревающие технологии

---

## 🟢 Adopt (внедрить)

| Технология                                 | Описание                          | Поддержка бизнес-сценариев                  |
|--------------------------------------------|-----------------------------------|---------------------------------------------|
| Data Lake / Lakehouse (S3 + Delta/Iceberg) | Хранилище аналитических данных    | Быстрая отчетность, масштабирование         |
| Event Streaming (Kafka)                    | Асинхронный обмен данными         | Независимость доменов, интеграции           |
| API Gateway                                | Единая точка входа                | Интеграция сервисов и партнёров             |
| Cloud Infrastructure (AWS/GCP/Azure)       | Облачная платформа                | Масштабирование, отказоустойчивость         |
| Data Catalog / Governance                  | Управление доступом и метаданными | Безопасность данных, self-service аналитика |
| Trino / Presto                             | SQL-доступ к Data Lake            | Self-service отчётность                     |

---

## Trial (пилотирование)

| Технология                | Описание                   | Поддержка                       |
|---------------------------|----------------------------|---------------------------------|
| Data Mesh                 | Доменная работа с данными  | Масштабирование и независимость |
| Feature Store             | Хранилище признаков для ML | AI-сценарии                     |
| Stream Processing (Flink) | Потоковая обработка        | near real-time аналитика        |
| Kubernetes                | Оркестрация контейнеров    | Масштабирование сервисов        |

---

## Assess (оценка)

| Технология       | Описание                        | Поддержка             |
|------------------|---------------------------------|-----------------------|
| GraphQL          | Гибкий доступ к данным          | Data Portal           |
| Data Contracts   | Контракты данных между доменами | Надёжность интеграций |
| ML Ops платформы | Управление ML жизненным циклом  | AI-домен              |

---

## Hold (устаревающее)

| Технология            | Причина                   |
|-----------------------|---------------------------|
| SQL Server 2008 (DWH) | Не масштабируется, легаси |
| PowerBuilder          | Устаревший UI             |
| ESB (Apache Camel)    | Высокая связанность       |
